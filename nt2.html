package documentation
(source)

CLI to convert between NestedText and other formats, with explicit type casting.

Currently supported formats:

  • JSON
  • YAML
  • TOML
  • HJSON
  • HUML (inherits known bugs of pyhuml)
  • MAML (inherits known bugs of maml-py)
  • XML (no type casting)
